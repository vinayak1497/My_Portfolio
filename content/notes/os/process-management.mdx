# Process Management

## What is a Process?

A process is a program in execution. It includes the program code, current activity, and associated resources.

## Process States

- **New** — Process is being created
- **Ready** — Process is waiting to be assigned to a processor
- **Running** — Instructions are being executed
- **Waiting** — Process is waiting for an event
- **Terminated** — Process has finished execution

## Scheduling Algorithms

### First Come First Served (FCFS)
Simplest scheduling algorithm. Non-preemptive.

### Shortest Job First (SJF)
Selects the process with the smallest execution time.

### Round Robin (RR)
Each process gets a small unit of CPU time (time quantum).
