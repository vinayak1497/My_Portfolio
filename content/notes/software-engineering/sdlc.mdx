# SDLC Models

## Waterfall Model
Linear sequential flow — Requirements → Design → Implementation → Testing → Deployment → Maintenance.

## Agile Methodology
Iterative development with sprints, daily standups, and continuous feedback.

### Scrum
- Sprints (1-4 weeks)
- Daily standup
- Sprint review & retrospective

### Kanban
- Visual workflow
- WIP limits
- Continuous delivery
